## Notable Game Development Tools

| Tool Name | Description |
| :---- | :---- |
| [V-Sekai Godot](https://github.com/V-Sekai/godot/) | The V-Sekai maintained branch of Godot Engine |
| [V-Sekai Manuals](https://github.com/V-Sekai/manuals) | Comprehensive manuals and guides for developing with and contributing to V-Sekai. |
| [V-Sekai Blender Game Tools](https://github.com/V-Sekai/V-Sekai.blender-game-tools) | A suite of Blender add-ons and utilities tailored for the V-Sekai game development workflow. |
| [Unidot Importer](https://github.com/V-Sekai/unidot_importer) | Godot Engine tool for importing assets and scenes from Unity Engine projects and Blender files. |
| [Godot VRM](https://github.com/V-Sekai/godot-vrm) | Godot Engine add-on providing support for the VRM 3D humanoid avatar format. |
| [Godot Paint Mixer](https://github.com/V-Sekai/godot-paint-mixer) | A utility within Godot Engine for intuitive mixing of paint colors and applying textures. |
| [Blender RigNet](https://github.com/V-Sekai/blender-rignet) | Advanced rigging tool for Blender aimed at automating and simplifying the character rigging process. |
| [Godot Task Goal Planner](https://github.com/V-Sekai/godot-task-goal-planner) | A classical AI planning system for Godot Engine, enabling goal-oriented behavior and task management for NPCs. |
| [Godot Splerger](https://github.com/V-Sekai/godot-splerger) | A mesh manipulation tool for Godot Engine designed for splitting and managing complex mesh structures. |
| [Godot Snappy](https://github.com/jgillich/godot-snappy) | A vertex snapping add-on for Godot Engine, enhancing precision in 3D modeling and level design. |
| [Lasso](https://github.com/V-Sekai/lasso) | A selection tool for Godot Engine, providing lasso-style selection capabilities for assets and objects. |
| [Hydro](https://github.com/godot-extended-libraries/hydro) | An extended library for Godot Engine focusing on realistic water and fluid simulation. |
| [Godot Sandbox](https://github.com/libriscv/godot-sandbox) | A sandboxed environment for Godot Engine, facilitating experimentation with RISC-V architecture integration. |
| [Quadwild BIMDF (TOOL\_quad\_mesh\_generator)](https://github.com/V-Sekai/TOOL_quad_mesh_generator) | An adaptive quad mesh generation tool for Godot, based on the Quadwild algorithm with BIMDF. |
| [Differentiable Cloth](https://github.com/fire/differentiable_cloth) | Simulation tool for cloth materials within a differentiable programming paradigm, enabling advanced physics. |
| [Godot Cage Deformer](https://github.com/V-Sekai-fire/TOOL_godot_cage_deformer) | A cage deformer add-on for Godot Engine. |
